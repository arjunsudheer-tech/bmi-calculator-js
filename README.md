## ✨ Features

- Calculate BMI using height and weight
- Height input in centimeters
- Weight input in kilograms
- BMI category detection
- Input validation
- Displays BMI result with two decimal places
- Calculate BMI using the Calculate button
- Press Enter to calculate BMI
- Clears input fields after calculation
- Responsive layout
- Clean and simple user interface

## 🧮 BMI Calculation

The calculator uses the standard BMI formula:

BMI = Weight (kg) / Height² (m)

For example:

Height = 170 cm
Weight = 70 kg

Height = 1.70 m

BMI = 70 / (1.70 × 1.70)
BMI = 24.22

The calculated BMI is categorized as:

BMI Range	Category
Below 18.5	Underweight
18.5 – 24.9	Normal
25 – 29.9	Overweight
30 and above	Obese
